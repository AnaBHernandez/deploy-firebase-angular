# 🛰️ Despliegue de Aplicación Angular en Firebase Hosting

## 📋 Descripción del Proyecto
Este repositorio contiene una práctica de infraestructura frontend orientada al despliegue optimizado de una aplicación **Angular 18** en el servicio de **Hosting de Firebase**, configurada bajo arquitectura de aplicación de una sola página (**SPA**).

El proyecto sirve como showcase de empleabilidad técnica para demostrar control de entornos locales Linux (Ubuntu 24.04 LTS), automatización y gestión de riesgos en despliegues en la nube.

## 🛠️ Tecnologías y Herramientas
* **Framework:** Angular 18 con Tailwind CSS para estilos.
* **Gestor de Paquetes:** `pnpm` (Optimización de espacio y rendimiento local).
* **Cloud Provider:** Firebase Hosting.
* **Control de Versiones:** Git con estrategia de *Feature Branches* (`feature/firebase-hosting`).
